# Image Processing JMH Benchmark Results - 2026-05-25

## Summary

This run refreshes the macOS Java 25 row for the `images-benchmark` module.
Historical CI Linux rows remain in
[`benchmark-results-2026-04-29.md`](benchmark-results-2026-04-29.md) until the

Lower `ms/op` is better. Scores are JMH `AverageTime` results with 3 warmup
iterations, 5 measurement iterations, and 1 fork.
