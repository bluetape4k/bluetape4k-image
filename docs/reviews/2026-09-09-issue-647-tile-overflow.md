|---|---|---|---|

두 검토자는 소스·호출자·실행 로그를 읽었으며 수정이나 테스트 중복 실행은 하지 않았다.
코드 리뷰의 비차단 의견 두 건은 반영했다. 정상 경계 테스트에서 두 픽셀을 모두 비교하고,
`@throws`에 양수가 아닌 크기와 실제 크기 불일치를 명시했다.

## 근거

- 양수의 올림 나눗셈에서 덧셈을 제거했다. 개수의 곱은 `Long`으로 계산하고
  `maxTileCount`를 확인한 다음 `Int`로 변환한다.
- 병합할 목록을 정렬한 사본에서 좌표·크기·실제 이미지·끝점을 검증한 뒤 할당하고 그린다.
- 수정 전 회귀 3개 실패·정상 1개 통과, 수정 후 타일 테스트 11개 통과.
- 전체 images 701개 통과, 실패 0. 작은 입력 속성 테스트 10개와 비활성 골든 이미지
  생성기 8개는 건너뛰었으며 통과 수에 포함하지 않았다.
- 공개 ABI 10개 모듈 및 변경 소스·새 회귀 테스트를 지정한 detekt 통과.

## 반론과 잔여 범위

실제 이미지와 다른 크기를 선언한 타일을 기존에는 허용했으나 이제 거부한다.
검증한 크기와 실제 그리는 크기가 달라 생긴 우회를 막는 의도된 입력 계약 강화이다.
공개 JVM 시그니처, 타일 정렬 순서와 그래픽 자원 종료 방식은 유지했다.
전체 출력 픽셀 예산과 알파 합성 반올림은 기존 동작이며 이번 좌표 산술 수정 범위가 아니다.
