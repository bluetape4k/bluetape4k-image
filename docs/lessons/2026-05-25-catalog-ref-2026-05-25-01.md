# 카탈로그 참조 2026-05-25-01

## 배경

공유 `bluetape4k-dependencies` 카탈로그에서 ASM, AWS Kotlin SDK,
Apache Fory 의존성을 갱신했다.

## 결정

기본 `bluetape4kDependenciesCatalogRef`가 `develop`을 계속 따라가지 않도록
`catalog/2026-05-25-01`에 고정한다.

## 결과

Gradle 설정은 기본적으로 릴리스 트레인 카탈로그를 가져오면서
`bluetape4kDependenciesCatalogRef` 또는
`BLUETAPE4K_DEPENDENCIES_CATALOG_REF`를 통한 재정의도 허용한다.

스냅샷 게시 워크플로는 `develop`을 강제로 체크아웃하지 않고 디스패치된 참조를
체크아웃한다. 따라서 브랜치 게이트를 거친 스냅샷 트레인 검증은 Nightly를 통과한
동일한 카탈로그 고정 소스를 게시한다.

## 검증

- `./gradlew compileTestKotlin --refresh-dependencies --console=plain -PsnapshotVersion=-SNAPSHOT`
- `actionlint .github/workflows/publish-snapshot.yml`

## 향후 방지책

조정된 의존성 트레인 갱신에는 날짜가 포함된 카탈로그 태그를 사용한다.
수동으로 디스패치한 스냅샷 게시 워크플로에서 `develop` 체크아웃을 강제하지
않는다. 검증과 게시가 같은 소스 트리를 사용하도록 디스패치 참조를 사용한다.
