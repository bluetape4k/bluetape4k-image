# 2026-05-20 — README 개요 시각 자료 배치

## 배경

README 다이어그램과 차트는 장식용 생성 자산이 아니라 소스에 근거한 문서로
다뤄야 한다. 이번 작업에서는 2026년 참조 문서와 공통 README 다이어그램 스타일
가이드를 사용했지만, 모듈 이름과 그룹의 기준은 소스 코드와 빌드 레이아웃으로
유지했다.

## 결정

루트 README에 영어 전용 SVG+PNG 개요 시각 자료를 추가하고, 개요 다이어그램을
설치, 사용법 또는 빌드 지침보다 앞에 배치한다. 기존 Architecture/Diagram
섹션이 사용 예제 뒤에 있으면 위로 옮긴다.

## 결과

`bluetape4k-image`에 루트 README 개요 다이어그램과 모듈 구성 차트를 추가했고,
README 시각 자료는 개요 우선 규칙을 따른다. 생성한 레이블은 이미지 내부에
현지화된 텍스트를 넣지 않는다.

## 검증

- 생성한 SVG 파일을 `xmllint --noout`으로 파싱했다.
- `rsvg-convert`로 PNG 파일을 렌더링했다.
- 워크스페이스 README 이미지 링크 검사에서 누락된 로컬 이미지가 없었다.
- 워크스페이스 Architecture/Diagram 순서 검사 결과 Installation, Usage,
  Examples, Build 제목 뒤에 남은 해당 섹션이 없었다.
- 생성한 루트 개요 SVG 텍스트에 비 ASCII 문자가 없었다.

## 향후 참고

아키텍처 다이어그램을 README 파일 끝에 추가하지 않는다. 개요 또는 아키텍처
다이어그램은 상단 가까이에 두고, 클래스, 시퀀스, ERD, 흐름 다이어그램은
설명하는 섹션 옆에 배치한다.

루트 개요 다이어그램과 구성 차트는 BOM이 있으면 첫 번째에, Examples 또는
Additional examples가 있으면 마지막에 배치한다. 중간 그룹은 저장소별 README가
알파벳순 그룹화를 요구하지 않는 한 소스에 근거한 방향 순서를 유지한다.
