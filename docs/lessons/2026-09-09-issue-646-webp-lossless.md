# #646 WebP 무손실 옵션 전달 누락

## 원인과 수정

JVips의 일반 `writeToArray(format, quality, strip)` 호출에는 무손실 인자가 없다.
공개 옵션이 존재하는지만 확인하면 실제 네이티브 호출에서 옵션이 사라지는 문제를 놓친다.
고정된 JVips 버전의 `writeWEBPToArray(quality, lossless, strip)`를 사용하도록 수정했다.
새 의존성이나 추상화를 추가하지 않았다.

## 검증 방법

두 구현이 같은 공개 경로 계약 테스트를 사용한다. WebP의 실제 RIFF 청크가
무손실 `VP8L`인지 확인하고, PNG로 다시 디코딩하여 반투명 픽셀의 RGBA 값을 비교한다.
기본 옵션은 기존 손실 압축 `VP8 `을 유지하는지도 확인한다.
완전히 투명한 픽셀의 숨겨진 RGB 보존은 이 계약의 범위가 아니다.

macOS ARM64에서는 포함된 JNI 라이브러리의 아키텍처가 맞지 않아 테스트가 건너뛰어졌다.
이를 통과로 처리하지 않고 Linux amd64 JDK 25와 libvips 환경에서 실행했다.
수정 전에는 `VP8 ` 때문에 실패했고, 수정 후 같은 테스트와 JNI 이미지 테스트 21개가
건너뜀 없이 통과했다. macOS FFM에서도 같은 공개 계약이 통과했다.

## 재발 방지

옵션을 전달하는 어댑터는 반환 바이트가 비어 있지 않은지만 검사하지 않는다.
실제 형식과 디코딩 결과를 검사하고, 구현 간 계약 테스트는 기존 시험용 공통 모듈에 둔다.
플랫폼에서 건너뛴 네이티브 테스트는 별도 실행 증거가 생길 때까지 검증 공백으로 기록한다.
