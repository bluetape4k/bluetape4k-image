# #647 타일 경계 산술과 선행 검증

## 잘못된 가정과 수정

작은 이미지를 처리하더라도 타일 크기나 좌표가 크면 `Int` 덧셈이 넘친다.
2×1 이미지와 `Int.MAX_VALUE`만으로 음수 배열 용량과 범위 밖 타일의 검사 통과를 재현했다.
양수의 올림 나눗셈은 `(value - 1) / divisor + 1`로 계산하고, 타일 개수의 곱과
좌표·크기의 합은 `Long`으로 비교한다. 허용 개수를 확인한 뒤에만 `Int`로 변환한다.
새 수학 라이브러리는 필요하지 않다.

병합은 타일 목록을 정렬한 사본에서 크기 양수 여부, 실제 이미지와의 크기 일치,
대상 영역 경계를 모두 검증한 다음 출력 이미지를 할당한다. 검증과 그리기에 같은
목록을 사용하여 호출자의 목록 변경으로 검사 대상이 달라지지 않도록 한다.

## 검증과 재발 방지

회귀 테스트는 작은 이미지로 최대 크기, 좌표 넘침, 음수 좌표, 크기 불일치,
정상 경계의 픽셀 결과를 확인한다. 수정 전 의도한 실패 3건과 정상 1건을 확인했고,
수정 후 기존 타일 테스트를 포함해 11개가 통과했다.

최초 정상 경계 시험에는 반투명 색을 썼지만 기존 Java2D 합성의 반올림으로 색상 값이
1 달라졌다. 좌표 검증과 합성 의미를 섞지 않도록 불투명 색으로 고쳤으며,
이번 수정에서 합성 알고리즘을 바꾸지 않았다.

작업 중 `mutation-check`에 다른 하위 명령용 인자를 전달해 명령이 실패했는데도
다음 편집이 실행되는 절차 오류가 있었다. 실제 승인 범위는 유지됐고 올바른 명령으로
재확인했지만, 앞으로 검사와 편집은 성공 응답을 확인한 뒤 별도 호출로 실행한다.
