# Image 0.3 매뉴얼 diagram 검토

다섯 매뉴얼 diagram을 3200 x 2080 픽셀로 렌더링한 뒤 검토했다.

## Contract 검증

- 어두운 매뉴얼 palette를 일관되게 사용한다.
- 모든 connector에 14 x 14 arrowhead와 보이는 도착 지점이 있다.
- 같은 영역을 공유하는 route는 대비되는 색 또는 별도 진입점을 사용한다.
- 접근성을 위한 SVG title과 description이 있다.
- 모든 diagram에 대응하는 SVG와 PNG asset이 있다.

## 전체 크기 시각 검토

- `overview/repository-learning-map`: label이 card 안에 남아 있고, 세 learning branch와 workshop 수렴이 명확하다.
- `architecture/processing-lifecycle`: 좁은 card의 label을 줄여 overflow를 막았고, main·retry·coroutine-boundary path가 시각적으로 구분된다.
- `backends/backend-decision-map`: JVM, JNI, FFM branch가 별도 색을 사용하며 숨겨진 connector segment가 없다.
- `integrations/ocr-web-flow`: Spring과 Ktor가 서로 다른 지점에서 image 경계로 진입하고, OCR·storage·operations arrow가 각 card에서 눈에 보이게 끝난다.
- `benchmarks/benchmark-interpretation-map`: 겹치는 fan-out route에 대비되는 색을 사용하고 environment와 decision arrow가 계속 보인다.

## 검증

```text
ruby scripts/manual/render_image_diagrams.rb
ruby scripts/manual/validate_diagrams.rb
Image diagram contract passed: 5 SVG/PNG pairs, accessible labels, directed connectors, and 14x14 arrowheads.
```
