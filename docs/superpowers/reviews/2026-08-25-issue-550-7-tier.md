## 독립 reviewer lifecycle

독립 reviewer는 원래 다음만 수행하도록 할당했다.

- 이 worktree의 네 문서를 read-only로 읽는다.
- ORT official source claim, Maven/version/license claim, platform matrix,
  lifecycle/security/CI boundary와 한국어 writer contract를 다시 검증한다.
- P0/P1/P2/P3 finding을 파일·heading·문장 근거와 함께 반환한다.
- 문서를 수정하거나 native/dependency 실행을 대신하지 않는다.
- timeout이면 workflow receipt에 `suspect_stall`/probe를 기록하고 timeout을 PASS로
  승격하지 않는다. grace 안에 결과가 없으면 main lane이 동일 범위의 inline review를
  수행하되 독립 검토 부재를 PENDING으로 남긴다.

독립 lane은 위 bounded window에 결과를 반환하지 않았다. 따라서 아래 inline 결과를
독립 PASS로 해석하지 않는다. 독립 결과가 `REQUEST CHANGES`로 돌아오는 경우에는
leader가 P0/P1을 먼저 수정하고, 사실·계약이
바뀐 문서는 SPW-01~05를 다시 읽는다. resolution lane 결과와 leader inline 결과를
한 문장으로 합치지 않는다.

## 리스크 판정 규칙

- P0: ORT/native 보안 우회, public API 또는 dependency를 이 문서 train에서 실제로
  추가, 또는 source-backed claim을 반대로 기록한 경우.
- P1: platform/BOM/version/license/lifecycle/CI gate가 후속 구현을 잘못 승인하게
  만드는 누락이나 모순.
- P2: 실행 계획·fixture·metadata의 재현성을 낮추는 누락이지만 adoption을 직접
  승인하지는 않는 경우.
- P3: 표현·교차 링크·writer 품질 문제.

`PENDING`인 native runtime, benchmark, Java 25, macOS ARM64, Windows x64 smoke는
결함이 아니라 명시된 후속 gate다. 이를 현재 문서의 PASS로 올리지 않는다.

## Leader pre-review evidence

- source ledger가 `settings.gradle.kts`, `images/build.gradle.kts`, BOM/publication
  inventory, OCR/native rules, #548/#549 문서를 참조한다.
- official URLs는 ORT Java guide, Java README, `OrtEnvironment`, `SessionOptions`,
  `Result`, `OnnxTensor`, EP/install/CUDA, Maven Central, ONNX external-data/security,
  ORT versioning/format docs를 포함한다.

  macOS ARM64는 확인되지 않는다. 따라서 ARM64는 지원 선언이 아니라 별도 consumer

  receipt 필수 항목이며 현재 수치를 native evidence로 가장하지 않았다.

  semantics, sanitized error, benchmark protocol을 분리했다.
- `#551 ADOPT` 전 implementation/dependency/native execution 금지를 research,
